Accessibility

Last updated: 15 September 2026

We want anyone to be able to learn about Jogoe, complete checkout, and download the installer. This site aims to meet WCAG 2.2 Level AA where practical.

What is in place

  • A skip link to jump past the header to the main content.
  • Page language set to English, with headings, landmarks, and labels on forms.
  • Keyboard access for menus, FAQs, buttons, and links, with a visible focus ring.
  • Text that can be enlarged; layout that works on phones and desktops.
  • Alt text on companion images, and reduced motion if your system asks for it.
  • Higher-contrast colors when your system requests more contrast.

Known limits

The Jogoe desktop app is a Windows overlay. Some app screens are still catching up to the same keyboard and screen-reader support as this website. Decorative motion on the orb is turned off when you prefer reduced motion.

How to use this site with a keyboard

  • Tab moves through links and controls. Shift+Tab moves backward.
  • Enter or Space activates buttons, including FAQs and the menu.
  • Escape closes the menu.

Report a problem

If something is hard to use, email hello@jogoe.app with the page, what you were trying to do, and the browser or assistive technology you use. We will work to fix it.
