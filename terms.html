What Jogoe can do

Jogoe is a Windows desktop companion. It is designed to:

  • Chat, tell jokes, tell stories, and answer questions using a local AI model on your PC
  • Speak out loud and listen when you use the microphone
  • Remember facts you ask it to store, and delete them when you ask
  • Tell the local time and date, and report CPU, RAM, disk, or battery use
  • Search common user folders (such as Desktop, Documents, Downloads, and Pictures) by file name
  • Search inside common text files for a keyword
  • Open a document it found with the default Windows app
  • Open everyday applications such as Notepad, Calculator, File Explorer, a web browser, Word, Excel, Paint, or Spotify
  • Change or mute system volume
  • Look up weather and simple public-web facts when you ask, if that setting is on
  • Send or read email only if you configure your own mail account in Settings
  • Lock, sleep, hibernate, restart, or shut down the PC only after you confirm in a prompt

You are responsible for what you ask Jogoe to do on your computer, within this list.
