What Jogoe can and cannot do

Jogoe is a desktop companion, not a technician with a terminal. Here is the honest list.

It can

Everyday help on this PC, in your words.

  • Chat, tell jokes, stories, and answer questions with a local AI model
  • Speak out loud and listen when you use the mic
  • Remember facts you ask it to keep, and forget them when you say so
  • Tell the time and date, and check CPU, RAM, disk, or battery
  • List files on Desktop, Documents, Downloads, Pictures, Videos, and Music
  • Search those folders by file name
  • Search inside common text files for a keyword
  • Open a document it found in the usual app (Word, PDF, Notepad, and similar)
  • Open everyday apps such as Notepad, Calculator, File Explorer, Chrome, Edge, Word, Excel, Paint, or Spotify
  • Set or mute volume
  • Look up weather and simple live facts when you ask, if internet lookup is on
  • Send or read mail only if you set up your own email in Settings
  • Lock, sleep, restart, or shut down the PC — only after you confirm in a prompt

It cannot

It is not a hacker, admin console, or full PC takeover.

  • Open Command Prompt, PowerShell, Windows Terminal, or any other terminal
  • Run commands, scripts, .bat files, or code you paste in
  • Install, uninstall, or update software
  • Hack, crack passwords, bypass logins, or break into other systems
  • Control other computers, other user accounts, or the web like a remote desktop
  • Click around Windows for you, change most system settings, or edit the registry
  • Browse your whole disk unprompted, or read every file by default
  • Read the insides of Word or PDF files yet (name search still works)
  • Guarantee that answers are always right — local models can be wrong
  • Replace a lawyer, doctor, or IT support person
  • Upload your chats to a Jogoe cloud, or train a public model on them
